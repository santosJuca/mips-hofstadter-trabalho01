# Capturas obrigatórias do MARS

Esta pasta deve receber as quatro evidências exigidas no trabalho.

## Arquivos a adicionar

1. `01_codigo_montado.png`
   - Mostrar o programa montado no MARS.
   - A área de código deve estar visível de forma legível.

2. `02_registradores_final.png`
   - Executar um caso completo.
   - Mostrar a janela de registradores ao término da execução.

3. `03_pilha_recursao.png`
   - Pausar a execução durante uma chamada recursiva de `female` ou `male`.
   - Mostrar a área de memória correspondente à pilha.
   - O objetivo é evidenciar os valores salvos e o endereço de retorno.

4. `04_execucao_completa.png`
   - Mostrar uma execução completa no console do MARS.
   - Recomenda-se usar `n = 4` ou outro valor que deixe a tabela legível.

## Resultado esperado para n = 4

```text
n       0   1   2   3   4
F(n)    1   1   2   2   3
M(n)    0   0   1   2   2
```

Não substituir estas evidências por imagens artificiais ou recriadas. As capturas devem ser feitas no MARS executando o arquivo entregue.
