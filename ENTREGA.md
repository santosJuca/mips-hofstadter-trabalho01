# Checklist de entrega

Antes de compactar e enviar:

- [ ] Preencher os nomes reais dos desenvolvedores em `hofstadter.asm`.
- [ ] Conferir a data exibida pelo programa.
- [ ] Abrir `hofstadter.asm` no MARS.
- [ ] Montar sem erros.
- [ ] Executar testes com valores pequenos.
- [ ] Confirmar `n = 4`: F = 1 1 2 2 3 e M = 0 0 1 2 2.
- [ ] Testar entrada negativa e confirmar encerramento.
- [ ] Salvar `capturas/01_codigo_montado.png`.
- [ ] Salvar `capturas/02_registradores_final.png`.
- [ ] Salvar `capturas/03_pilha_recursao.png`.
- [ ] Salvar `capturas/04_execucao_completa.png`.
- [ ] Finalizar a documentação.
- [ ] Exportar a documentação em PDF.
- [ ] Conferir que o código Assembly mostrado no PDF é o mesmo arquivo entregue.
- [ ] Criar um ZIP contendo o PDF e o arquivo `hofstadter.asm`.
